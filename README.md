# SBR GoGo Auto Runner — Edge 浏览器扩展

『[GO!GO! HORSE RUN!](https://sbr-gogo.jojo-portal-anime.com/game/)』（动画《Steel Ball Run JoJo的奇妙冒险》官方小游戏）的自动驾驶扩展：自动交替踏步，把速度**稳定保持在最大值附近且永不滑倒（SLIP）**，并自动拍碎仙人掌、驱赶对手、收集小熊。

## 功能

| 功能 | 说明 |
|---|---|
| 🏃 稳定最大速度 | 严格交替 ←/→ 踏步，反馈控制踏频把速度比稳定在 ~93–97%，永不触发 SLIP（速度×0.3 + 900ms 锁定的惩罚） |
| ⚡ BEYOND 加速 | 捡到小熊（含自动收集）触发 2 倍速冲刺期间全力踏步吃满加成 |
| 🔨 自动清障 | 自动点击屏幕上的仙人掌（拍碎 +5s）、对手（驱赶 → 机会神击 +5s）、小熊（+5s / BEYOND） |
| 🎛 状态面板 | 页面右下角：实时速度比、状态与开关（偏好自动保存在本机） |

## 安装（Microsoft Edge）

1. 打开 Edge，地址栏输入 `edge://extensions` 回车。
2. 打开左下角「**开发人员模式**」开关。
3. 点击「**加载解压缩的扩展**」，选择扩展目录（`sbr-gogo` 文件夹）。
4. 访问 <https://sbr-gogo.jojo-portal-anime.com/game/>，扩展自动开始工作（右下角出现「SBR 自动驾驶」面板）。

> 开局由你手动进行：选择地区 → 点击开始 → 跳过说明 → 倒计时结束起跑后，扩展自动接管踏步与清障。

## 工作原理（逆向自游戏代码）

- 游戏监听 `document` 的 `keydown`（`ArrowLeft`/`ArrowRight` → L/R），交替踏步每次给马加一个冲量（同侧只有 50% 效果），速度由空气阻力（随速度平方增长）平衡。
- 连续踏步时内部气力槽涨到 1，速度上限随之到 `vMax=21`；一旦速度顶到上限（速度比 ≥1 且 HUD ≥99.5% 持续 10ms）就触发 **SLIP**：速度×0.3、气力清零、900ms 无法踏步。所以满速狂按必然滑倒——必须留余量悬停。
- 扩展读取 HUD 速度表（`#gmGaugeBar` 宽度 = 平滑速度比），用**双积分器**自动校准踏频（次/秒）把速度比稳定在目标值，外加速度过冲时的暂停护栏与打滑后自动回退，三层保险保证稳定。
- 对手/仙人掌/小熊都是运行期生成、带 `pointerdown` 处理器的 PIXI 对象。`hook.js` 在游戏脚本加载前拦截 `window.PIXI` 与 `Container.prototype.on/eventMode`，登记这些对象；`auto.js` 每 300ms 扫描其屏幕位置并合成 `pointerdown` 完成拍碎/驱赶/收集。
- 脚本均在 **MAIN world** 运行（需要直接派发页面能收到的事件），本扩展不修改任何游戏逻辑、不上传任何数据、成绩只保存在本地 localStorage。

## 文件结构

```
sbr-gogo/
├── manifest.json    # MV3 清单（两个 MAIN world 内容脚本）
├── hook.js          # document_start：捕获 PIXI 应用实例 + 登记可交互对象
├── auto.js          # document_idle：控制器 / 清障 / 状态面板
└── icons/           # 扩展图标
```

## 面板开关

- **ON/OFF 徽章**：总开关。
- **自动清障**：自动点击仙人掌/对手/小熊（游戏进行中）。

所有偏好保存在站点 localStorage（`sbrAutoPrefs`），清除站点数据即可重置。
